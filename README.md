# 🏆 Projeto World Cup 2026

## 📌 Sobre o projeto

O **Projeto World Cup 2026** é uma aplicação web desenvolvida para apresentar informações sobre a Copa do Mundo de 2026 por meio de uma interface moderna, dinâmica e totalmente responsiva. O projeto reúne dados das seleções participantes, estatísticas, títulos conquistados e outros conteúdos relacionados ao maior campeonato de futebol do mundo, proporcionando uma navegação intuitiva e agradável para os fãs do esporte.

O principal objetivo deste projeto é demonstrar habilidades em desenvolvimento Front-End, utilizando HTML, CSS e JavaScript para construir uma aplicação visualmente atrativa, organizada e otimizada para diferentes dispositivos.


## ⚽ Funcionalidades

-🏆 Apresentação da Copa do Mundo de 2026;
- 🌍 Exibição das seleções participantes;
- 📊 Informações e estatísticas das equipes;
- 🥇 Ranking de títulos das seleções campeãs;
- 🚩 Bandeiras e identidade visual das equipes;
- 📱 Layout totalmente responsivo;
- ⚡ Navegação rápida e intuitiva;
- 🎨 Interface moderna e organizada;
- ✨ Animações para melhorar a experiência do usuário.


## 🚀 Tecnologias Utilizadas

- HTML5 🟧
- CSS3 🟦
- JavaScript 🟨


## 📱 Responsividade

O projeto foi desenvolvido seguindo os princípios de **Responsive Web Design**, garantindo uma excelente experiência de navegação em computadores, tablets e smartphones.


## 🎯 Objetivos do Projeto

Este projeto foi criado para:

- Demonstrar conhecimentos em desenvolvimento Front-End;
- Praticar manipulação e organização de informações esportivas;
- Desenvolver uma interface moderna e responsiva;
- Aplicar boas práticas de HTML, CSS e JavaScript;
- Criar uma experiência visual agradável para os usuários.



## 🌟 Destaques do Projeto

- Interface moderna e elegante;
- Excelente organização visual;
- Navegação simples e intuitiva;
- Código limpo e estruturado;
- Responsividade para diferentes dispositivos;
- Design focado na experiência do usuário (UI/UX);
- Componentes reutilizáveis e de fácil manutenção.
